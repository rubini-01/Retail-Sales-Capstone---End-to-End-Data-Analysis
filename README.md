# End-to-End Retail Sales Capstone Project

## Overview
A complete hands-on project analyzing retail sales data using **Excel, SQL, Python, and Power BI**.  
Built as part of a Data Analyst Training Program to demonstrate multi-tool integration and business insights.

## Datasets
- Sales (12,150 rows)
- Customers (500 rows)
- Products (70 rows)
- Returns (480 rows)
- Monthly Targets (336 rows)

## Tools & Deliverables
- **Excel**: Data cleaning, VLOOKUP, pivot charts, target analysis → `retail_cleaned.xlsx`
- **SQL**: Multi-table joins, profitability, return rate, window functions → `queries.sql`
- **Python**: EDA, outlier detection, visualizations (line, bar, scatter) → `analysis.ipynb`
- **Power BI**: Interactive dashboard with KPIs & visuals → `dashboard.pbix`, `dashboard.pdf`

## Key Insights
- ₹48.2L Revenue, ₹6.8L Profit, 12,430 Orders
- 3.9% Return Rate, Avg Customer Age: 38 yrs
- 87% Target Achievement across regions

## Skills Demonstrated
Data Cleaning · SQL Joins · Window Functions · Pandas · NumPy · Matplotlib · Power BI · KPI Reporting · Dashboard Design
